# Лабораторные работы 7-8

## Тема
Отладка и сохранение данных формы в JSON в проекте `Bottle` (`FishPoint`).

## Что выполнено
1. Доработан обработчик формы `POST /home` в `myform.py`.
2. Реализована запись данных формы в словарь:
   - `email` -> `[USERNAME, QUESTION]` (`LAST_FORM_DATA`).
3. Реализовано накопление данных в JSON-файле `data/questions.json`.
4. Структура JSON:
   - `email` -> `{ "username": "...", "questions": ["..."] }`.
5. Для одного и того же `email` вопросы добавляются в список.
6. Дубликаты вопросов не записываются повторно.
7. Добавлены проверки:
   - все поля обязательны;
   - email должен соответствовать шаблону;
   - длина вопроса больше 3 символов;
   - вопрос не может состоять только из цифр.
8. Для демонстрации отладки выведена отладочная печать словаря:
   - `print("DEBUG LAST_FORM_DATA:", LAST_FORM_DATA)`.

## Файлы ЛР 7-8
- `myform.py` - обработка формы, валидация, запись в JSON.
- `data/questions.json` - файл накопления вопросов пользователей.

## Пример записи в JSON
```json
{
  "user@example.com": {
    "username": "Олег",
    "questions": [
      "Есть ли катушки 3000 размера?",
      "Когда новая поставка воблеров?"
    ]
  }
}
```
