# Лабораторные работы 5-6

## Тема
Разработка и обработка формы обратной связи в `Bottle`-проекте `FishPoint`.

## Что выполнено
1. На главную страницу добавлена форма `Ask a Question`.
2. Форма содержит:
   - `textarea` для вопроса (`QUEST`);
   - поле имени пользователя (`USERNAME`);
   - поле email (`ADRESS`);
   - кнопку отправки `Send` с классом `btn btn-default`.
3. Размер `textarea` сделан неизменяемым (`resize: none`).
4. Создан отдельный обработчик формы в файле `myform.py`.
5. В `app.py` подключен модуль обработки формы.
6. Реализованы проверки:
   - заполненность всех полей;
   - корректность формата email (через регулярное выражение).
7. В сообщении результата добавлены:
   - обращение по имени пользователя;
   - дата обращения в формате `YYYY-MM-DD`.

## Регулярное выражение email
Использованный паттерн:
`^[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}$`

## Исключительные ситуации и результаты тестирования
- Пустое имя: выводится ошибка о необходимости заполнить все поля.
- Пустой email: выводится ошибка о необходимости заполнить все поля.
- Пустой вопрос: выводится ошибка о необходимости заполнить все поля.
- Некорректный email (например, `abc@`): выводится ошибка о формате email.
- Корректный ввод: выводится подтверждение `Thanks, <USERNAME> ... Access Date: <DATE>`.

## Дополнительно (контрольный вопрос)
Регулярное выражение для номера телефона формата `+7 (xxx) xxx-xx-xx`:
`^\+7 \(\d{3}\) \d{3}-\d{2}-\d{2}$`
