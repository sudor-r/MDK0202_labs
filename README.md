# Лабораторные работы 2-4

## Тема
Рыболовный магазин `FishPoint` на шаблоне `Bottle`.

## Выполненные этапы
1. Создана структура проекта `Bottle` с шаблонами страниц.
2. Подготовлены страницы: `Главная`, `Каталог`, `О магазине`, `Контакты`.
3. Добавлены статические артефакты: стили (`CSS`) и изображения (`SVG`).
4. Сформирована UML-диаграмма компонентов: `docs/uml-components.puml`.
5. Подготовлен перечень артефактов и протоколов.

## Перечень артефактов проекта
- `app.py` - точка входа приложения.
- `routes.py` - маршруты и обработчики страниц.
- `views/layout.tpl` - общий шаблон с навигацией.
- `views/index.tpl` - домашняя страница.
- `views/catalog.tpl` - страница каталога товаров.
- `views/about.tpl` - страница с описанием магазина.
- `views/contact.tpl` - страница контактов.
- `static/css/site.css` - стили интерфейса.
- `static/images/logo.svg` - логотип сайта.
- `static/images/hero.svg` - иллюстрация для главной страницы.
- `requirements.txt` - зависимости Python-проекта.
- `README.md` - описание проекта и инструкции запуска.

## Используемые протоколы
- `HTTP` - протокол взаимодействия браузера с локальным сервером во время разработки.
- `HTTPS` - рекомендуемый протокол для публикации проекта и безопасной передачи данных.
- `Git` - протокол/механизм контроля версий для истории изменений.

## Примечание по GitHub
Проект готов к публикации в удаленном репозитории `GitHub` и совместной работе через `clone`, `commit`, `push`, `pull`.
